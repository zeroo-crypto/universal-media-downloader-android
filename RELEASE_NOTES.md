### Unduh APK Langsung

Pilih salah satu file di bagian **Assets** di bawah:
- **`app-release.apk`** (Ukuran universal, dapat dipasang di semua merk HP Android).
- **`app-arm64-v8a-release.apk`** (Khusus HP Android 64-bit modern, ukuran file lebih kecil).

---

### Cara Pasang di HP Android:
1. Unduh file `app-release.apk` langsung ke ponsel Anda.
2. Buka file hasil unduhan.
3. Jika muncul peringatan keamanan *"Aplikasi dari sumber tidak dikenal"*, pilih **Pengaturan** dan aktifkan **Izinkan dari sumber ini**.
4. Tekan **Pasang** / **Install**.

---

### Cara Menggunakan:
- **Metode 1 (Menu Bagikan)**: Buka YouTube, Pixiv, Twitter/X, TikTok, Instagram, atau Pinterest di HP -> tekan tombol **Bagikan** (*Share*) -> pilih **Universal Downloader**.
- **Metode 2 (Manual)**: Buka aplikasi -> tempel URL pada kolom yang tersedia -> tekan **Periksa URL** -> pilih resolusi/format -> tekan **Unduh Sekarang**.

---

### Fitur Utama:
- Berjalan 100% di HP tanpa membutuhkan server atau PC.
- Otomatis merakit animasi Pixiv Ugoira (ZIP frame) menjadi video MP4 berkualitas tinggi.
- Penataan folder otomatis: `Download/Media/<Platform>/<Nama_Kreator>/...`.
- Pembersihan otomatis file sementara jika unduhan terputus atau dibatalkan.
